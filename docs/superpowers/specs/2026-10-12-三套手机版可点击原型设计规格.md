# 三套手机版可点击原型设计规格

## 目标

为乐秀平台制作三套可切换的 390×844 手机版可点击原型。每套都从登录开始，覆盖工作台、应用分组、业务列表、详情、表单、附件上传/审核、返回和角色限制的关键路径，供北於在本机逐套比较 UI 风格。

## 三种视觉方向

| 主题参数 | 金曜掌上台 | 浅雾清单 | 蓝域掌控 |
| --- | --- | --- | --- |
| 主题 key | `lounge` | `ledger` | `orbit` |
| 核心感受 | 黑金、门店管理、重点提醒 | 米白、清单、低负担操作 | 深蓝、数据、状态监控 |
| 主色 | `#d1ad63` | `#087e72` | `#65b9ff` / `#a45bff` |
| 页面底色 | 深炭黑 | 象牙白 | 深海军蓝 |
| 导航方式 | 底部四项导航 | 顶部轻量导航 | 顶部导航 + 数据优先级卡 |
| 卡片语言 | 金色线条、圆角卡片 | 细边框、紧凑清单 | 深色面板、状态徽章 |

三套主题共享同一业务信息架构和同一组虚拟演示数据，差异集中在色彩、层级、间距、导航位置和模块呈现方式，避免因为换主题而改变业务流程。

## 可点击范围

### 入口与身份

1. 本地原型入口页可以选择三种主题，并显示统一 Logo。
2. 每套主题都有独立登录页，使用虚拟账号：管理员 `demo-admin / demo123`，普通员工 `demo-staff / demo123`。
3. 身份切换会回到登录页，登录后按角色呈现允许/限制入口；不会调用真实登录接口。

### 主流程

1. 登录 → 工作台。
2. 工作台 → 应用分组/模块入口。
3. 企业证照、员工健康证、固定资产、仓库库存、审核中心、酒水单、设置均可进入列表。
4. 列表 → 搜索/筛选 → 详情。
5. 详情 → 编辑或新建表单 → 分步填写 → 选择虚拟附件 → 预览确认 → 保存。
6. 审核中心 → 通过或打回 → 返回审核列表。
7. 消防档案入口沿用现有固定目录页，作为可进入的业务模块；照片操作保留虚拟演示，不写入真实数据库。
8. 所有二级页都有明确返回路径，操作结果用原型提示反馈。

## Logo 规范

- Logo 源文件使用用户提供的 `D:\乐秀酒水海报与本地工具\用户勾选图片整理-20261011\logo图片\重复图片审计缩略图-d0077.jpg`。
- 由于源文件是带浅灰底的缩略图，原型只做裁切和背景透明化处理，不改字形、不重绘 Logo；生成独立原型资产，不覆盖生产 Logo。
- 登录、页头、工作台、公开酒水单和消防档案入口统一引用该派生资产。

## 本地运行和数据边界

- 入口只在 `SHOW_PREVIEW=True` 的本机直跑模式下开放，正式 gunicorn 不注册可见入口。
- 原型页面使用内存虚拟数据；不读取、修改、迁移 `data/app.db` 或 `data/uploads/`。
- 不新增依赖，不上传服务器，不改变生产页面和业务 API。

## 验收标准

- 三种主题均能在 390×844 手机视口从登录点击到工作台、模块列表、详情、表单、上传/审核和返回。
- 管理员与普通员工演示身份均可登录；管理员专属入口在普通员工身份下显示限制反馈。
- 主题切换不会丢失入口页选择，也不会把三套主题同时堆叠在一屏。
- 390px 和 320px 宽度无横向滚动，按钮触控高度至少 44px，长中文标题可换行。
- 入口、主题、角色、核心路由和虚拟写操作都有自动化契约检查；浏览器实际点击覆盖三套主题。
- 现有消防页面改动和生产数据库内容不受影响。
