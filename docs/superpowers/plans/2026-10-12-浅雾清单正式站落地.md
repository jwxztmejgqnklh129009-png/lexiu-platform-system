# 浅雾清单正式站落地实施计划

目标：把已确认的浅雾清单移动端视觉方案落到现有 Flask 正式模板，保留现有业务逻辑、接口、权限与数据。

## 任务

- [x] 阅读正式模板、样式和导航状态机，确认最小改动范围。
- [x] 编写正式站页面清单、字段、流程、权限和验收标准。
- [x] 先建立 `test_ledger_site_theme.py` 契约并确认旧模板失败。
- [x] 给登录、工作台和消防页增加 `theme-ledger` 范围标记。
- [x] 在工作台显示统计、快捷操作、提醒区、资料 / 物资 / 协作分组和四项移动底栏。
- [x] 追加浅雾主题 CSS，统一 Logo、颜色、卡片、导航和移动断点。
- [x] 同步消防页品牌外壳，不改消防业务流程。
- [x] 运行契约测试、消防测试、编译、JavaScript 语法和差异检查。
- [x] 重启本机 Flask 服务并验证登录页面已加载新主题。

## 验收边界

- 本轮只做本机正式页面 UI 落地，不操作 `data/`，不打包、不上传、不部署。
- 真实账号和生产业务数据不用于本轮自动化写入验证。
- 正式站 320px 真实浏览器视口需在用户本机验收阶段补测。
