# 乐秀平台产品与体验优化实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 v1.14.7 基础上改善现有页面的导航上下文、异步状态、键盘/焦点、响应式布局和主题一致性，并用隔离数据完成本机验证。

**Architecture:** 保留 Flask、SQLite、原生 JavaScript/CSS 和现有 API。第一阶段只调整模板、前端脚本和样式；后端不新增业务表、不改生产数据、不改变 admin/staff 权限边界。所有异步页面继续使用现有 `api()`/`post()` 封装，统一补充加载、失败、重试和请求竞态保护。

**Tech Stack:** Flask + SQLite；原生 JavaScript/CSS；现有 PowerShell/Python 隔离测试入口；浏览器页面验证使用本机隔离服务。

**Spec:** `docs/superpowers/specs/2026-10-11-乐秀平台产品与体验优化设计方案.md`
