# 三套手机版可点击原型 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 基于现有全站虚拟原型，交付三套可切换、手机优先、从登录到业务操作各层级可点击的乐秀移动端 UI 原型。

**Architecture:** 复用 `docs/黑金方案-20261005/黑金全站原型.html` 内已有的虚拟数据和路由渲染逻辑，抽取为独立的本地原型文件；入口页用主题参数选择 `lounge`、`ledger`、`orbit`，每次只渲染一个主题。Flask 只增加 `SHOW_PREVIEW` 保护的静态文件入口，生产运行不会开放。

**Tech Stack:** Flask 现有预览开关、原生 HTML/CSS/JavaScript、现有虚拟原型状态机、Pillow（仅一次性处理 Logo 资产）。不新增运行时依赖，不触碰生产 SQLite。

**Spec:** `docs/superpowers/specs/2026-10-12-三套手机版可点击原型设计规格.md`

## Global Constraints

- 原型只在 `SHOW_PREVIEW=True` 的本机直跑模式开放。
- 原型使用内存虚拟数据，禁止写入 `data/app.db` 和 `data/uploads/`。
- 用户提供的 Logo 只做裁切和背景透明化派生，不能重绘字形或覆盖现有生产 Logo。
- 三套主题共享同一业务流程，但同一时刻只显示一个主题。
- 不改动既有消防页面、审计报告、复测结论和生产业务 API。
- 不打包、不上传、不部署，等用户后续明确批准。
