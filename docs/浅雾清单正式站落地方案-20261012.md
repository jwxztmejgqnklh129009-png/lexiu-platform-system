# 浅雾清单正式站落地方案

日期：2026-10-12  
目标版本：本机开发验证版  
范围：现有 Flask 正式页面的 UI 落地，不涉及生产数据、接口和服务器发布

## 1. 页面清单

- 登录页：浅雾灰绿品牌入口、Logo、账号表单和公开酒水单入口。
- 工作台：问候区、资料统计、提醒摘要、状态总览、分组业务入口。
- 应用页：资料模块、物资模块、协作模块三组可收缩入口。
- 企业证照 / 员工健康证：沿用现有业务数据和操作，统一为移动优先资料卡。
- 消防档案：保留既有目录列表、目录详情、照片上传和打印流程，仅同步品牌外壳。
- 我的：保留账号、修改密码、退出和管理员工具。

## 2. 字段清单

- 工作台统计：企业证照、员工健康证、固定资产、库存品项、资料总数、过期、15 天内到期、长期有效、待确认、正常有效。
- 提醒摘要：证照到期和库存预警的已过期、15 天内到期、库存不足数量。
- 资料卡：资料名称、分类、有效期状态、到期日、附件预览、详情、删除（仅管理员）。
- 身份信息：当前账号名称、角色、管理员可见功能。

## 3. 操作流程

1. 登录后进入浅雾工作台。
2. 点击提醒摘要进入提醒明细，再进入对应资料或物品详情。
3. 点击工作台分组入口进入证照、健康证、资产、库存、消防、审核、酒水单或设置。
4. 移动端底部导航在工作台、资料、物资、我的之间切换。
5. 现有上传、编辑、删除、审核、打印接口和权限逻辑保持不变。

## 4. 权限要求

- 管理员和普通员工沿用现有后端权限。
- 普通员工不显示审核中心、酒水单、系统设置的后台入口。
- 删除资料、管理员工具和审核操作仍由后端权限控制，UI 只负责展示。
- 原型预览入口仍仅在本机直跑模式开放，不改变正式 gunicorn 行为。

## 5. 验收标准

- 桌面端和手机端使用浅雾灰绿视觉，Logo 统一，页面无明显横向溢出。
- 工作台首屏能看到统计、提醒摘要和分组入口。
- 应用页三组入口可展开 / 收起，点击后能到达原有页面。
- 证照、健康证、消防档案的既有业务流程不被破坏。
- 管理员与普通员工入口差异保持正确。
- Python 编译、现有原型契约、正式站主题契约、浏览器页面和控制台检查通过。
- 不修改 `data/app.db`、`data/uploads/`，不打包、不上传、不部署。
