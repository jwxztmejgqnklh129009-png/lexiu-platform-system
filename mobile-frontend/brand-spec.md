# 品牌与组件依据

- 沿用原项目 `../static/` 中的 Logo 和 favicon，原样存放在 `public/assets/lexiu-brand/`，未重绘。
- 原界面依据为 `../templates/index.html`、`../static/style.css`、`../static/app.js`，业务规则依据为 `../app.py`。
- 基础按钮、表单、选择器、上传、弹层、导航和图片预览采用正式 Vant 4.10.2（MIT）；包装只承担主题、业务组合和本机读写适配，不另写基础行为。
- 日间白灰、夜间深灰，少量蓝色用于操作；品牌蓝是本次确认的设计选择，不是对 Logo 官方色值的推断。
- 保留工作台/资料/物资/我的四入口；分组列表与分隔线组织内容，常规分组不使用装饰阴影。
- 默认跟随系统，可在“我的”手动覆盖。图片不反色，状态同时使用文字和颜色表达。
- 使用设备中文字体；间距以4/8/12/16/24px为主，内容左右16px，常用控件圆角8px，分组12px。
- 演示酒单及档案图片均在图内明确标记，不能作为真实售价、证件或消防现场证据。

这是已完成本轮验证的前端演示版，验证范围和仍需完成的工作见 [验收说明](docs/acceptance.md)。

组件文档与许可证来源：[Vant 4.10.2](https://github.com/youzan/vant/tree/v4.10.2)。
