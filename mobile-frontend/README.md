# 乐秀 KTV 手机前端演示版

这是本仓库现有管理功能的独立手机前端，采用 Vue 3、TypeScript 和 Vant 4.10.2 正式组件。保留原 Logo、员工/管理员两种角色、公开酒水单，以及“工作台 / 资料 / 物资 / 我的”四个入口。

**本次交付为前端演示：不调用 Flask API，不替换原模板，不连接生产数据。** 角色、登录和审核仅在浏览器内模拟；不应将其用于真实账号认证或门店正式运营。

## 本地运行

Node.js 要求：`^20.19.0 || >=22.12.0`（与锁定的 Vite 要求一致）。本次交付在 Node.js 24.14.0、npm 11.9.0 验证。

在本仓库根目录执行：

```bash
cd mobile-frontend
npm ci
npm run dev
```

打开 <http://127.0.0.1:5190/>。默认进入员工演示，顶部身份按钮或“我的 → 切换演示身份”可进入管理员演示。

```bash
npm run build        # TypeScript 检查并输出 dist/
npm run preview      # 构建后预览 http://127.0.0.1:4190/
npm run test:demo    # 隔离存储的演示状态/组件回归，不连接后端
```

构建产物和依赖未提交到 Git。开发预览和构建预览的端口不同，本机演示数据相互独立。

## 文件保存在哪里

- 文字记录放在当前浏览器的 localStorage；图片、PDF、Word/Excel 文件本体放在 IndexedDB。
- 刷新可继续查看；不同浏览器、地址、端口和设备不共享数据。清理浏览器数据会丢失演示改动。
- 文件没有上传到服务器。选择文件、保存中、待审核和已生效分别显示；保存中禁止提前提交和离开。
- 仓库/酒单/消防接收 JPG、PNG；证照另支持 PDF、DOC、DOCX、XLS、XLSX。文件受类型、大小、内容和像素校验。
- SVG 仅用于初始演示样张，明确标记虚构酒单、非真实证件或非现场照片；用户上传不能借此绕过格式限制。
- 文字台账不包含附件文件或密码摘要，不是完整备份。重置会清除本机演示改动，按确认框说明执行。
